# LoveOfUs AI 层开发文档

## 一、项目概述

AI 层基于 **FastAPI + PyTorch** 构建，作为独立微服务提供照片智能分析能力。接收 Spring Boot 后端的图片分析请求，返回结构化分析结果。

### 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| FastAPI | 0.110+ | 高性能异步 Web 框架 |
| Uvicorn | 0.29+ | ASGI 服务器 |
| PyTorch | 2.x | 深度学习框架 |
| CLIP | 最新 | 多模态模型（标签 + 场景）|
| FaceNet | 最新 | 人脸识别与聚类 |
| Pillow | 10.x | 图像处理 |
| Celery | 5.x | 异步任务队列（可选）|
| Redis | 7.x | 任务队列 Broker |

**人脸注册流程：**
```
1. 用户上传含两人合照
2. 检测两张人脸，提取特征向量
3. 分别标记为 user_id 和 partner_id
4. 后续照片自动识别并标记
```

### 4.8 智能精选算法

基于多维度评分系统，从大量照片中筛选最佳照片：

```python
# 综合评分公式
def calculate_score(photo):
    score = (
        photo.quality_score * 0.3 +      # 图片质量 30%
        photo.emotion_score * 0.25 +     # 情绪评分 25%
        photo.diversity_score * 0.2 +    # 多样性 20%
        photo.time_coverage * 0.15 +     # 时间覆盖 15%
        photo.scene_importance * 0.1     # 场景重要性 10%
    )
    return score
```

**多样性算法：**
- 使用照片特征向量聚类
- 确保选中的照片覆盖不同场景
- 避免相似照片重复

**时间覆盖算法：**
- 按时间段均匀采样
- 确保不同时期都有代表性照片
- 重要日期（纪念日、节日）优先
