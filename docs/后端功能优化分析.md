#### 代码优化点

```java
// AuthServiceImpl.java - 建议增加登录失败次数限制
private static final int MAX_LOGIN_ATTEMPTS = 5;
private static final int LOCK_DURATION_MINUTES = 30;

private boolean isAccountLocked(String account) {
    String lockKey = "login:lock:" + account;
    return Boolean.TRUE.equals(redisTemplate.hasKey(lockKey));
}

private void recordLoginFailure(String account) {
    String failKey = "login:fail:" + account;
    Long count = redisTemplate.opsForValue().increment(failKey);
    if (count != null && count >= MAX_LOGIN_ATTEMPTS) {
        redisTemplate.opsForValue().set(failKey, String.valueOf(count), 
            LOCK_DURATION_MINUTES, TimeUnit.MINUTES);
    }
}

private void clearLoginFailures(String account) {
    redisTemplate.delete("login:fail:" + account);
    redisTemplate.delete("login:lock:" + account);
}
```

## 三、性能优化分析

### 3.1 数据库优化

#### 3.1.1 索引优化

| 表名 | 建议索引 | 说明 |
|------|----------|------|
| `photo` | `idx_user_date` (user_id, taken_date) | 优化时间线查询 |
| `photo` | `idx_province_city` (province, city) | 优化地点筛选 |
| `album` | `idx_group_id` (group_id) | 优化情侣相册查询 |
| `photo_album` | `idx_album_photo` (album_id, photo_id) | 优化相册照片关联 |

#### 3.1.2 查询优化

```sql
-- 优化前：全表扫描
SELECT * FROM photo WHERE user_id = ? ORDER BY taken_date DESC;

-- 优化后：使用覆盖索引
SELECT id, taken_date, storage_path FROM photo 
WHERE user_id = ? AND is_deleted = 0 
ORDER BY taken_date DESC 
LIMIT ?, ?;
```

### 3.2 缓存优化

#### 3.2.1 缓存策略

| 缓存类型 | 过期时间 | 说明 |
|----------|----------|------|
| 用户信息 | 永不过期 | 手动清除 |
| 用户统计 | 当天零点 | 自动过期 |
| 相册列表 | 永不过期 | 手动清除 |
| 相册详情 | 永不过期 | 手动清除 |
| 照片详情 | 永不过期 | 手动清除 |
| 验证码 | 60秒 | 自动过期 |

#### 3.2.2 缓存优化建议

| 优化项 | 说明 |
|--------|------|
| **缓存预热** | 系统启动时预加载热门数据 |
| **缓存穿透** | 使用布隆过滤器或空值缓存 |
| **缓存雪崩** | 过期时间增加随机值 |
| **缓存击穿** | 使用互斥锁或永不过期策略 |
