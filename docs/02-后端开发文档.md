# LoveMap 后端开发文档

## 一、项目概述

LoveMap 后端基于 **Spring Boot 4.0 + MyBatis + MySQL + Redis**，提供 RESTful API 供前端调用，处理用户认证、照片存储管理、相册组织、照片导出等功能。

### 技术栈

| 技术              | 版本    | 说明         |
| --------------- | ----- | ---------- |
| Spring Boot     | 4.0.6 | 基础框架       |
| Spring Security | 6.x   | 认证授权       |
| MyBatis         | 3.x   | ORM 框架     |
| MySQL           | 8.x   | 关系型数据库     |
| Redis           | 7.x   | 缓存 + 会话管理  |
| MinIO           | 最新    | 对象存储（照片文件） |
| Lombok          | 最新    | 代码简化       |

## 四、统一响应格式

### 4.1 响应体结构

```java
public class Result<T> {
    private int code;        // 状态码
    private String message;  // 提示信息
    private T data;          // 数据
    private long timestamp;  // 时间戳

    // 成功响应
    public static <T> Result<T> success(T data) {
        return new Result<>(200, "success", data);
    }

    // 失败响应
    public static <T> Result<T> error(int code, String message) {
        return new Result<>(code, message, null);
    }

    // 分页响应
    public static <T> Result<PageResult<T>> page(List<T> list, long total, int page, int size) {
        return success(new PageResult<>(list, total, page, size));
    }
}
```

### 4.2 状态码定义

| Code | 说明             |
| ---- | -------------- |
| 200  | 成功             |
| 400  | 请求参数错误         |
| 401  | 未认证 / Token 过期 |
| 403  | 无权限            |
| 404  | 资源不存在          |
| 409  | 资源冲突（如重复绑定）    |
| 413  | 文件过大           |
| 422  | 验证失败           |
| 429  | 请求过于频繁         |
| 460  | 验证码错误          |
| 461  | 验证码已过期         |
| 462  | 验证码发送过于频繁      |
| 500  | 服务器内部错误        |

## 五、API 接口定义

### 5.1 认证模块 `/api/auth`

#### POST `/api/auth/captcha/send` - 发送验证码

向指定手机号或邮箱发送验证码，用于注册、登录、找回密码等场景。

**请求参数：**

```json
{
  "target": "13800138000",
  "channel": "sms",  // 发送渠道：sms / email
  "type": "register"  // 验证码类型：register / login / reset_password / bind_phone
}
```

**参数说明：**

| 参数      | 类型     | 必填 | 说明                       |
| ------- | ------ | -- | ------------------------ |
| target  | String | 是  | 手机号或邮箱地址                 |
| channel | String | 是  | 发送渠道：`sms`短信 / `email`邮箱 |
| type    | String | 是  | 验证码用途类型                  |

**发送渠道说明：**

| 渠道    | 说明            |
| ----- | ------------- |
| sms   | 短信验证码，发送到手机号  |
| email | 邮件验证码，发送到邮箱地址 |

**验证码类型说明：**

| 类型              | 用途         |
| --------------- | ---------- |
| register        | 用户注册       |
| login           | 手机号/邮箱快捷登录 |
| reset\_password | 重置密码       |
| bind\_phone     | 绑定新手机号     |
| bind\_email     | 绑定新邮箱      |

**响应：**

```json
{
  "code": 200,
  "message": "验证码发送成功",
  "data": {
    "expireSeconds": 300,
    "cooldownSeconds": 60
  }
}
```

**错误响应：**

| Code | 说明                 |
| ---- | ------------------ |
| 400  | 手机号格式错误            |
| 409  | 手机号已注册（register类型） |
| 462  | 发送过于频繁，请稍后再试       |

#### POST `/api/auth/captcha/verify` - 验证验证码

验证用户输入的验证码是否正确（可选接口，用于前端预校验）。

**请求参数：**

```json
{
  "phone": "13800138000",
  "captcha": "123456",
  "type": "register"
}
```

**响应：**

```json
{
  "code": 200,
  "message": "验证成功",
  "data": {
    "valid": true
  }
}
```

#### POST `/api/auth/register` - 注册

**请求参数：**

```json
{
  "nickname": "小可爱",
  "phone": "13800138000",
  "email": "love@example.com",
  "password": "Abc12345",
  "confirmPassword": "Abc12345",
  "captcha": "123456",       // 短信验证码
  "partnerCode": "LOVE2024"  // 可选，伴侣绑定码
}
```

**参数说明：**

| 参数              | 类型     | 必填 | 说明                |
| --------------- | ------ | -- | ----------------- |
| nickname        | String | 是  | 昵称，2-20字符         |
| phone           | String | 是  | 手机号               |
| email           | String | 否  | 邮箱                |
| password        | String | 是  | 密码，8-20位，需包含字母和数字 |
| confirmPassword | String | 是  | 确认密码              |
| captcha         | String | 是  | 短信验证码，6位数字        |
| partnerCode     | String | 否  | 伴侣绑定码             |

**响应：**

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": 1,
    "token": "eyJhbGci...",
    "expiresIn": 86400,
    "userInfo": {
      "nickname": "小可爱",
      "avatarUrl": null,
      "isBound": false
    }
  }
}
```

**错误响应：**

| Code | 说明              |
| ---- | --------------- |
| 460  | 验证码错误           |
| 461  | 验证码已过期          |
| 422  | 密码不符合要求或两次密码不一致 |
| 409  | 手机号已被注册         |

#### POST `/api/auth/login` - 登录

支持密码登录和验证码快捷登录两种方式。

**方式一：密码登录**

**请求参数：**

```json
{
  "account": "13800138000",
  "password": "Abc12345",
  "loginType": "password",
  "captcha": "123456"  // 可选，安全验证时要求输入
}
```

**方式二：验证码快捷登录**

**请求参数：**

```json
{
  "account": "13800138000",
  "captcha": "123456",
  "loginType": "captcha"
}
```

**参数说明：**

| 参数        | 类型     | 必填 | 说明                      |
| --------- | ------ | -- | ----------------------- |
| account   | String | 是  | 手机号或邮箱                  |
| password  | String | 否  | 密码（密码登录时必填）             |
| captcha   | String | 条件 | 验证码（快捷登录必填，密码登录可选）      |
| loginType | String | 是  | 登录方式：password / captcha |

**响应：** 同注册响应。

**错误响应：**

| Code | 说明            |
| ---- | ------------- |
| 460  | 验证码错误         |
| 461  | 验证码已过期        |
| 401  | 账号或密码错误（密码登录） |
| 404  | 账号不存在         |

#### GET `/api/auth/bind-code` - 获取我的绑定码

获取当前用户的伴侣绑定码。如果用户已有未过期的绑定码则直接返回，没有则返回空。

**响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "bindCode": "LOVE2024",
    "expireTime": "2026-06-07T12:00:00",
    "expireSeconds": 3600,
    "isBound": false
  }
}
```

**参数说明：**

| 字段            | 类型      | 说明                       |
| ------------- | ------- | ------------------------ |
| bindCode      | String  | 绑定码，8位字母数字组合，无绑定码时为 null |
| expireTime    | String  | 过期时间 ISO8601格式           |
| expireSeconds | Integer | 剩余有效秒数                   |
| isBound       | Boolean | 当前用户是否已绑定伴侣              |

#### POST `/api/auth/bind-code/generate` - 生成绑定码

为当前用户生成伴侣绑定码。如果用户已有未过期的绑定码则直接返回现有码。

**响应：**

```json
{
  "code": 200,
  "message": "绑定码生成成功",
  "data": {
    "bindCode": "LOVE2024",
    "expireTime": "2026-06-07T12:00:00",
    "expireSeconds": 3600
  }
}
```

**参数说明：**

| 字段            | 类型      | 说明             |
| ------------- | ------- | -------------- |
| bindCode      | String  | 绑定码，8位字母数字组合   |
| expireTime    | String  | 过期时间 ISO8601格式 |
| expireSeconds | Integer | 剩余有效秒数         |

**业务规则：**

- 已绑定的用户不能生成绑定码
- 如果已有未过期的绑定码，直接返回现有码，不会重新生成
- 默认有效期为1小时

**错误响应：**

| Code | 说明              |
| ---- | --------------- |
| 409  | 用户已绑定伴侣，无法生成绑定码 |

#### POST `/api/auth/bind-code/refresh` - 刷新绑定码

主动刷新当前用户的绑定码，旧绑定码立即失效。

**响应：**

```json
{
  "code": 200,
  "message": "绑定码已刷新",
  "data": {
    "bindCode": "LOVE5678",
    "expireTime": "2026-06-07T13:00:00",
    "expireSeconds": 3600
  }
}
```

**业务规则：**

- 已绑定的用户不能刷新绑定码
- 新绑定码生成后，旧绑定码立即失效
- 默认有效期为1小时

#### POST `/api/auth/bind` - 绑定伴侣

使用伴侣提供的绑定码进行绑定。

**请求参数：**

```json
{
  "partnerCode": "LOVE2024"
}
```

**参数说明：**

| 参数          | 类型     | 必填 | 说明         |
| ----------- | ------ | -- | ---------- |
| partnerCode | String | 是  | 伴侣提供的8位绑定码 |

**响应：**

```json
{
  "code": 200,
  "message": "绑定成功",
  "data": {
    "isBound": true,
    "partner": {
      "id": 2,
      "nickname": "大笨蛋",
      "avatarUrl": "https://cdn.example.com/avatars/2.jpg"
    },
    "relationshipStart": "2026-06-07",
    "daysTogether": 1
  }
}
```

**业务逻辑：**

1. 验证绑定码是否有效（存在且未过期）
2. 验证双方是否都未绑定
3. 建立双向伴侣关系
4. 记录绑定起始日期
5. 双方绑定码立即失效

**错误响应：**

| Code | 说明              |
| ---- | --------------- |
| 404  | 绑定码不存在或已过期      |
| 409  | 当前用户已绑定 / 对方已绑定 |
| 400  | 不能绑定自己          |

#### POST `/api/auth/unbind` - 解除绑定（可选）

解除与伴侣的绑定关系。此操作需要双方确认或等待冷静期。

**请求参数：**

```json
{
  "confirm": true,
  "reason": "双方协商解除"  // 可选
}
```

**响应：**

```json
{
  "code": 200,
  "message": "解除绑定申请已提交，7天后正式生效",
  "data": {
    "effectiveDate": "2026-06-14T10:00:00",
    "cooldownDays": 7
  }
}
```

**业务规则：**

- 解除绑定有7天冷静期
- 冷静期内可随时取消解除申请
- 正式解除后，双方照片互相不可见
- 解除后可重新生成绑定码

#### POST `/api/auth/refresh` - 刷新 Token

**请求参数：**

```json
{
  "refreshToken": "xxx"
```

**业务逻辑：**

| album 表      | 该用户的所有相册                                                 |
| photo\_album | 关联该用户照片的记录（通过照片关联）                                       |
| 伴侣关系         | 自动解除，对方 is\_bound → 0                                    |

### 5.7 消息通知模块 `/api/notifications`

#### GET `/api/notifications/subscribe` - SSE订阅消息推送

建立SSE（Server-Sent Events）连接，实时接收服务端推送的消息通知。

**请求参数：**

| 参数     | 类型      | 必填 | 说明     |
| ------ | ------- | -- | ------ |
| userId | Integer | 是  | 用户ID   |

**请求示例：**

```javascript
// 前端使用 EventSource 建立连接（通过 URL 参数传递 userId）
const userId = userStore.userInfo?.id;
const eventSource = new EventSource(`/api/notifications/subscribe?userId=${userId}`);

// 监听连接成功事件
eventSource.addEventListener('connected', (event) => {
  const data = JSON.parse(event.data);
  console.log('SSE连接成功', data);
});

// 监听新消息通知
eventSource.addEventListener('new-notification', (event) => {
  const notification = JSON.parse(event.data);
  console.log('收到新通知:', notification);
});

// 监听未读数更新
eventSource.addEventListener('unread-count', (event) => {
  const { count } = JSON.parse(event.data);
  console.log('未读数量:', count);
});

// 监听心跳
eventSource.addEventListener('heartbeat', (event) => {
  console.log('心跳:', JSON.parse(event.data));
});

// 监听错误
eventSource.onerror = (error) => {
  console.error('SSE连接错误:', error);
  // 自动重连逻辑
};
```

**SSE事件类型：**

| 事件名称            | 说明                 | 数据格式                                                     |
| --------------- | ------------------ | -------------------------------------------------------- |
| new-notification | 新消息通知              | `{ id, type, typeName, title, content, businessId, createdAt }` |
| unread-count    | 未读数量更新             | `{ count: 3 }`                                           |
| heartbeat       | 心跳（每30秒一次）         | `{ timestamp: "2026-06-12T14:00:00" }`                   |
| connected       | 连接成功               | `{ userId: 1, connectedAt: "2026-06-12T14:00:00" }`      |
| error           | 服务端错误              | `{ code: 500, message: "服务器内部错误" }`                     |

**事件数据示例：**

```json
// new-notification 事件
{
  "id": 1,
  "type": 2,
  "typeName": "纪念日提醒",
  "title": "纪念日提醒",
  "content": "明天是你们在一起的第100天，记得给TA一个惊喜哦~",
  "businessId": 1,
  "createdAt": "2026-03-14T09:00:00"
}

// unread-count 事件
{
  "count": 3
}

// heartbeat 事件
{
  "timestamp": "2026-06-12T14:00:00"
}
```

**业务规则：**

- 每个用户只能建立一个SSE连接，重复连接会关闭旧连接
- 连接超时时间为30分钟，超时后需重新建立
- 心跳间隔为30秒，客户端可据此判断连接状态
- 当用户触发通知操作（如伴侣上传照片）时，服务端会向伴侣的SSE连接推送消息

#### 前端集成示例

```typescript
// notification.ts - 通知服务
class NotificationService {
  private eventSource: EventSource | null = null;
  private reconnectTimer: number | null = null;
  private reconnectCount = 0;
  private maxReconnectCount = 5;

  // 建立SSE连接
  connect(token: string) {
    if (this.eventSource) {
      this.disconnect();
    }

    this.eventSource = new EventSource('/api/notifications/subscribe', {
      headers: { 'Authorization': `Bearer ${token}` }
    });

    // 监听连接成功
    this.eventSource.addEventListener('connected', (e) => {
      console.log('SSE连接成功', JSON.parse(e.data));
      this.reconnectCount = 0;
    });

    // 监听新消息
    this.eventSource.addEventListener('new-notification', (e) => {
      const notification = JSON.parse(e.data);
      this.handleNewNotification(notification);
    });

    // 监听未读数更新
    this.eventSource.addEventListener('unread-count', (e) => {
      const { count } = JSON.parse(e.data);
      this.updateUnreadBadge(count);
    });

    // 监听心跳
    this.eventSource.addEventListener('heartbeat', (e) => {
      console.log('心跳', JSON.parse(e.data));
    });

    // 监听错误
    this.eventSource.onerror = () => {
      this.handleReconnect();
    };
  }

  // 断开连接
  disconnect() {
    if (this.eventSource) {
      this.eventSource.close();
      this.eventSource = null;
    }
    if (this.reconnectTimer) {
      clearTimeout(this.reconnectTimer);
      this.reconnectTimer = null;
    }
  }

  // 重连逻辑
  private handleReconnect() {
    if (this.reconnectCount >= this.maxReconnectCount) {
      console.error('SSE重连次数超限');
      return;
    }

    this.reconnectCount++;
    const delay = Math.min(1000 * Math.pow(2, this.reconnectCount), 30000);
    
    this.reconnectTimer = window.setTimeout(() => {
      const token = localStorage.getItem('token');
      if (token) {
        this.connect(token);
      }
    }, delay);
  }

  // 处理新通知
  private handleNewNotification(notification: any) {
    // 显示系统通知
    this.showSystemNotification(notification.title, notification.content);
    // 更新未读徽章
    this.fetchUnreadCount();
  }

  // 显示系统通知
  private showSystemNotification(title: string, content: string) {
    if (Notification.permission === 'granted') {
      new Notification(title, { body: content });
    }
  }

  // 获取未读数（用于初始化）
  private async fetchUnreadCount() {
    const res = await request.get('/api/notifications/unread-count');
    this.updateUnreadBadge(res.data.unreadCount);
  }

  // 更新未读徽章
  private updateUnreadBadge(count: number) {
    // 更新UI徽章
    document.querySelector('.notification-badge').textContent = count.toString();
  }
}

export const notificationService = new NotificationService();
```

## 七、认证与安全

### 7.1 JWT 认证

```
Token 结构：
  Access Token (24h) + Refresh Token (30天)

Token Payload:
{
  "userId": 1,
  "partnerId": 2,
  "iat": 1717747200,
  "exp": 1717833600
}
```

### 7.2 权限控制

- 未登录用户：仅可访问登录/注册页面
- 已登录用户：可查看自己的所有照片
- 情侣关系：彼此可互相查看照片
- 照片删除/修改：仅上传者可操作（或双方）

### 7.3 安全措施

| 措施     | 说明                        |
| ------ | ------------------------- |
| 密码存储   | BCrypt 加密                 |
| 接口限流   | Redis + 令牌桶，每个用户 100 次/分钟 |
| 验证码安全  | 6位数字，有效期5分钟，单次使用，发送冷却60秒  |
| 短信防刷   | 单手机号每日上限10条，IP限流          |
| 图片安全   | 上传时扫描恶意内容，限制文件类型仅图片       |
| CORS   | 仅允许前端域名访问                 |
| XSS 防护 | 输入过滤 + HTML 转义            |
| SQL 注入 | MyBatis 参数预编译             |
| 敏感脱敏   | 手机号、邮箱返回时脱敏               |

### 7.4 验证码安全策略

**防刷机制：**

1. **发送频率限制**：同一手机号60秒内只能发送一次验证码
2. **日发送上限**：同一手机号每天最多发送10条验证码
3. **IP限流**：同一IP每小时最多发送20条验证码
4. **图形验证码**：连续发送3次后要求输入图形验证码

**验证码存储：**

- 使用Redis存储，Key格式：`captcha:{phone}:{type}`
- 过期时间：5分钟
- 验证成功后立即删除，防止重复使用

### 9.1 全局异常处理器

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBusiness(BusinessException e) {
        return Result.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidation(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(er -> er.getField() + ": " + er.getDefaultMessage())
            .collect(Collectors.joining("; "));
        return Result.error(422, msg);
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleException(Exception e) {
        log.error("unexpected error", e);
        return Result.error(500, "服务器内部错误");
    }
}
```
