## 一、功能概述

### 1.1 业务目标

为 `LoveOfUs` 情侣应用增加 **「AI 化妆建议」** 功能：用户上传一张自拍照 + 选择 / 描述场景，AI 服务：

1. 分析用户**脸型、肤色、眉眼特征**等基本信息；
2. 结合**场景**（约会 / 通勤 / 派对 / 旅行 / 婚礼等）生成**妆容 + 发型 + 配饰 + 服装**改造建议；
3. 异步生成**改造效果图**（Before / After 对比），通过 SSE 推送至前端。

### 1.2 关键决策（与 PM 已对齐）

| 决策点 | 选定方案 | 理由 |
|---|---|---|
| AI 能力来源 | **通义千问 Qwen-VL（多模态）** | 复用现有 `DashScope` + `langchain4j`，零新增依赖 |
| 改造图生成 | **异步任务 + SSE 推送** | 与现有导出任务风格一致，体验最佳 |
| 自拍照存储 | **OSS 长期保存 + 数据库记录** | 支持「历史化妆建议」回看 |
| 前后端交付 | **前后端两份独立指导文档** | 与 docs/01-06 风格统一 |

### 1.3 不在本期范围

- ❌ 视频版本改造效果（仅图片 Before/After）
- ❌ 多人合影分脸建议（仅单人单图）
- ❌ 妆容迁移效果图的二次编辑（用户不能调整参数）
- ❌ 海外场景（仅中文输出）

### 5.4 订阅进度（SSE）

```
GET /api/makeover/{recordId}/stream
Accept: text/event-stream
```

帧格式（与现有 AI Chat SSE 对齐）：

| event | data | 触发时机 |
|---|---|---|
| `stage` | `{ "stage": "analyze", "status": "running" }` | 文本分析开始 |
| `stage` | `{ "stage": "analyze", "status": "done" }` | 文本建议落库 |
| `stage` | `{ "stage": "image_edit", "status": "running" }` | 出图开始 |
| `done`  | `{ "recordId": 10001 }` | 全部完成 |
| `error` | `{ "message": "..." }` | 任意阶段失败 |

> **实现**：用 `Redis Pub/Sub` + `SseService` 现有能力（参考 `NotificationService`）。前端断连后改用 5.2 轮询兜底。

### 5.5 删除 / 取消

- `DELETE /api/makeover/{recordId}`：软删除，仅删自己
- `POST /api/makeover/{recordId}/cancel`：仅在 `status ∈ {0,1}` 时可取消

## 六、核心实现指引

### 6.1 Controller 模板（节选）

> 严格遵循 `PhotoController.uploadPhotos` 风格：multipart + `@RequestAttribute("userId")` + Swagger 注解。

```java
@Slf4j
@RestController
@RequestMapping("/makeover")
@RequiredArgsConstructor
@Tag(name = "AI 化妆建议")
public class MakeoverController {

    private final MakeoverService makeoverService;
    private final SseService sseService;

    @PostMapping(consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    @Operation(summary = "提交化妆建议（异步）")
    public Result<MakeoverCreateVO> create(
            @RequestAttribute("userId") Integer userId,
            @RequestPart("image") MultipartFile image,
            @RequestParam("scene") String scene,
            @RequestParam(value = "description", required = false) String description) {
        // 1) 参数校验：scene 必须命中枚举；image 类型/大小
        // 2) 调用 service.create，返回 recordId
        MakeoverCreateDTO dto = new MakeoverCreateDTO();
        dto.setScene(scene);
        dto.setDescription(description);
        return Result.success(makeoverService.create(userId, image, dto));
    }

    @GetMapping("/{id}")
    @Operation(summary = "化妆建议详情")
    public Result<MakeoverDetailVO> detail(
            @RequestAttribute("userId") Integer userId,
            @PathVariable Long id) {
        return Result.success(makeoverService.detail(userId, id));
    }

    @GetMapping(value = "/{id}/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    @Operation(summary = "订阅化妆建议进度")
    public SseEmitter stream(
            @RequestAttribute("userId") Integer userId,
            @PathVariable Long id) {
        // 沿用 PhotoController 鉴权模式：SseEmitter 长连接 + userId 校验
        SseEmitter emitter = new SseEmitter(5 * 60 * 1000L);
        sseService.register(makeoverChannel(id), emitter, userId);
        // 立即推送当前快照，避免前端空白期
        sseService.pushSnapshot(makeoverChannel(id), currentStage(id));
        return emitter;
    }

    @GetMapping
    @Operation(summary = "我的化妆建议列表")
    public Result<PageResult<MakeoverListVO>> list(
            @RequestAttribute("userId") Integer userId,
            @RequestParam(defaultValue = "1") Integer page,
            @RequestParam(defaultValue = "10") Integer size) {
        return Result.success(makeoverService.list(userId, page, size));
    }

    @DeleteMapping("/{id}")
    @Operation(summary = "删除化妆建议")
    public Result<Void> delete(
            @RequestAttribute("userId") Integer userId,
            @PathVariable Long id) {
        makeoverService.softDelete(userId, id);
        return Result.success();
    }
}
```

> ⚠️ SecurityConfig：现有 `anyRequest().authenticated()` 已覆盖 `/makeover/**`，**无需新增白名单**。

### 6.2 Service 实现要点

`MakeoverServiceImpl.create` 流程：

```
1. 校验 image (size ≤ 8MB、mime ∈ {jpg,png,webp})
2. 上传 OSS → key = "LoveMap/makeover/origin/{userId}/{yyyyMM}/{uuid}.{ext}"
   复用 PutObjectAsyncUtils.uploadFile，不另起新组件
3. 落库 makeover_record (status=0)
4. 投递 @Async → MakeoverAsyncExecutor.run(recordId)
5. 返回 MakeoverCreateVO
```

`MakeoverAsyncExecutor.run` 流程：

```
Stage 1 文本分析
 ├─ 更新 record.status = 1
 ├─ SSE 推送 stage=analyze running
 ├─ 构造 PromptBuilder.build(userId, sceneCode, sceneText, originalUrl)
 │   - 系统提示词：「你是专业彩妆师 + 造型师，输出严格 JSON」
 │   - 场景提示词：根据 sceneCode 注入模板
 │   - 图片：originalUrl (Qwen-VL 支持 URL)
 ├─ 调用 langchain4j ChatModel.chat(prompt + image)
 │   - 复用 dashscopeChatModel Bean
 │   - modelName 优先用 qwen-vl-plus；若该模型在用户当前套餐不可用，回落到 qwen-vl-max
 ├─ MakeoverResultParser.parse(content)
 │   - 解析失败 → 记录 error_message，终止
 ├─ 落库 record.face_features / record.suggestions
 └─ 更新 record.status = 2，SSE 推送 stage=analyze done

Stage 2 改造图生成
 ├─ SSE 推送 stage=image_edit running
 ├─ 调用 MakeoverImageProvider.edit(originalUrl, makeupPrompt, outfitPrompt)
 │   - 默认实现：DashScope wanx2.1-imageedit
 │   - 超时 90s（@Async 线程池 + CountDownLatch 控制）
 ├─ 接收 OSS → key = "LoveMap/makeover/after/{userId}/{yyyyMM}/{uuid}.png"
 ├─ 落库 record.after_url / after_key
 ├─ record.status = 3
 ├─ costMs = now - createdAt
 └─ SSE 推送 done

任意阶段异常：
 ├─ 记录 error_message
 ├─ record.status = 4
 └─ SSE 推送 error
```

### 6.5 改造图生成

`MakeoverImageProvider` 接口：

```java
public interface MakeoverImageProvider {
    /** 上传原图，返回改造图字节流 */
    byte[] edit(String originalUrl, String editPrompt, int timeoutSeconds);
}
```

默认实现 `DashScopeWanxImageProvider`：

- 调用 DashScope `wanx2.1-imageedit` 接口（POST），body 含 `function: "stylization_all" / "colorization"` 等参数；
- 实际参数选择交给前端回传的场景（**MVP 阶段先用 `description_edit` + prompt 描述妆容/服装变化**）；
- 超时上限 90s，失败重试 1 次后放弃。

> 💡 若 DashScope 改造图效果不达标，将本实现替换为 `StableDiffusionImageProvider`（自部署）或 `MeituApiProvider`（调用美图 API），**无需改动 Controller/Service**。

### 6.6 异步执行

`MakeoverAsyncExecutor`：

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class MakeoverAsyncExecutor {

    private final MakeoverTaskMapper taskMapper;
    private final MakeoverRecordMapper recordMapper;
    private final MakeoverPromptBuilder promptBuilder;
    private final MakeoverImageProvider imageProvider;
    private final MakeoverTaskEventBus eventBus;
    private final AliyunOSSUtils ossUtils;

    /** 复用现有 @Async 线程池（AsyncConfig 已配置） */
    @Async("aiTaskExecutor")
    public void run(Long recordId) {
        long start = System.currentTimeMillis();
        MakeoverRecord rec = recordMapper.selectById(recordId);
        try {
            // Stage 1
            updateStatus(rec, 1, null);
            eventBus.pushStage(recordId, "analyze", "running");
            String json = promptBuilder.analyze(rec.getOriginalUrl(),
                    rec.getSceneCode(), rec.getSceneText());
            // 解析 + 落库 face_features / suggestions
            ...
            updateStatus(rec, 2, null);
            eventBus.pushStage(recordId, "analyze", "done");

            // Stage 2
            eventBus.pushStage(recordId, "image_edit", "running");
            String editPrompt = buildImagePrompt(rec); // 由 suggestions 拼装
            byte[] img = imageProvider.edit(rec.getOriginalUrl(), editPrompt, 90);
            String afterUrl = ossUtils.asyncUploadBytes(img, buildAfterKey(rec));
            // 落库 after_url / after_key
            updateStatus(rec, 3, System.currentTimeMillis() - start);
            eventBus.pushDone(recordId);
        } catch (Exception e) {
            log.error("[Makeover] recordId={} failed", recordId, e);
            updateStatus(rec, 4, e.getMessage());
            eventBus.pushError(recordId, e.getMessage());
        }
    }
}
```

## 八、与其他模块的协作

### 8.1 复用现有能力清单

| 现有能力 | 文件 | 本次用途 |
|---|---|---|
| JWT 鉴权 | `JwtAuthFilter` | 接口鉴权 |
| OSS 上传 | `PutObjectAsyncUtils` / `AliyunOSSUtils` | 自拍照 & 改造图上传 |
| SSE 推送 | `SseService` | 进度推送 |
| 异步线程池 | `AsyncConfig` | `@Async("aiTaskExecutor")` |
| 限流 | `RateLimiterService` | 用户级防刷 |
| 统一响应 | `Result<T>` | 所有接口 |
| 软删除约定 | `deleted` 字段 | 记录删除 |
| Swagger | `springdoc-openapi` | 接口文档 |
| ChatModel Bean | `LangChain4jConfig` | 调用 Qwen-VL |

### 8.2 不复用的能力

- ❌ `AiChatService` / `AiChatMessage`：化妆建议**不写聊天消息**，有独立 session
- ❌ LangChain4j Tool（`@Tool`）：本功能不需要让 LLM 主动调工具，全部由 Service 编排

### 8.3 是否接入 AI Chat？

**建议**：把化妆建议作为 **独立入口**（菜单项 `AI 化妆建议`），不混入 AI Chat 流。  
原因：聊天场景上下文会污染 Prompt；状态机也更复杂。如未来需要「在聊天里 @ 调用化妆建议」，可在 `LangChain4jConfig.aiToolSpecifications` 中新增 `MakeoverTool`（参见 §10 拓展建议）。
