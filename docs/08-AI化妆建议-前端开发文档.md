## 一、功能概述

为 LoveOfUs 移动端新增 **「AI 化妆建议」** 模块，提供：

- **自拍照 + 场景** 提交入口；
- **分析进度**实时推送（SSE，断线降级为轮询）；
- **Before / After 对比图**与**妆造建议**详情；
- **历史记录**列表与回看。

### 1.1 用户旅程

```
首页 / Love Hub
  └─「AI 化妆建议」入口
       ├─ 首次：上传自拍照 → 选场景 → 可选描述 → 提交
       │       ↓
       │   [进度页：阶段 1 文本分析 ▸ 阶段 2 改造出图]
       │       ↓ (SSE 推送完成)
       │   [结果页：Before / After + 建议卡片]
       │
       └─ 二次：进入历史列表 → 点开某条 → 结果页
```

### 1.2 设计原则（与项目一致）

- **渐进式体验**：提交后立即给反馈，不阻塞首屏
- **网络兜底**：SSE 失败自动降级为 1.5s 轮询
- **隐私提示**：上传前明确告知「图片将保存至云端用于生成建议」
- **与 AI Chat 解耦**：独立入口、独立会话，不污染聊天历史

### 3.3 接口方法

```ts
import request from '@/utils/request'
import { sseGet } from '@/utils/sse'         // 已有 SSE 工具

/** 提交化妆建议 */
export function createMakeover(
  image: File,
  scene: SceneCode,
  description?: string,
  onUploadProgress?: (p: number) => void
): Promise<MakeoverCreateVO> {
  const fd = new FormData()
  fd.append('image', image)
  fd.append('scene', scene)
  if (description) fd.append('description', description)
  return request.post<MakeoverCreateVO>('/makeover', fd, {
    headers: { 'Content-Type': 'multipart/form-data' },
    onUploadProgress
  })
}

/** 查询详情 */
export function getMakeoverDetail(recordId: number): Promise<MakeoverDetailVO> {
  return request.get<MakeoverDetailVO>(`/makeover/${recordId}`)
}

/** 列表 */
export function listMakeover(page = 1, size = 10) {
  return request.get<PageResult<MakeoverListVO>>('/makeover', { params: { page, size } })
}

/** 软删 */
export function deleteMakeover(recordId: number): Promise<void> {
  return request.delete(`/makeover/${recordId}`)
}

/** 订阅进度（SSE） */
export function subscribeMakeoverProgress(
  recordId: number,
  onEvent: (e: MakeoverSseEvent) => void,
  onError: (err: Error) => void
): () => void {
  return sseGet({
    url: `/makeover/${recordId}/stream`,
    onEvent: (raw) => {
      try {
        const data = JSON.parse(raw.data)
        if (raw.event === 'stage')   onEvent({ stage: data.stage, status: data.status })
        else if (raw.event === 'done')  onEvent({ recordId: data.recordId })
        else if (raw.event === 'error') onEvent({ message: data.message })
      } catch (e) {
        onError(e as Error)
      }
    },
    onError
  })
}
```

> ⚠️ 若 `utils/sse.ts` 当前仅暴露 `ssePost`，需要新增 `sseGet`（GET + EventSource）。**改造方式**：在 `sse.ts` 末尾增加 `export function sseGet({ url, onEvent, onError, headers })`，内部用 `new EventSource(...)` 并在 `onmessage` 中派发。改动仅 30 行内。

```ts
const fileList = ref<any[]>([])
const form = reactive<{ scene: SceneCode; description: string }>({
  scene: 'date',
  description: ''
})
const submitting = ref(false)

const canSubmit = computed(() => fileList.value.length === 1 && !!form.scene)

async function onSubmit() {
  const file = fileList.value[0].file as File
  if (!file) return
  submitting.value = true
  try {
    const vo = await createMakeover(file, form.scene, form.description)
    showToast('已提交，正在分析中...')
    router.replace({ name: 'MakeoverProgress', params: { recordId: String(vo.recordId) } })
  } catch (e: any) {
    showFailToast(e?.message || '提交失败，请稍后再试')
  } finally {
    submitting.value = false
  }
}
```

### 4.2 `MakeoverProgress.vue`（进度页）

**核心**：SSE 订阅 + 轮询兜底 + 阶段卡片。

```ts
const recordId = computed(() => Number(route.params.recordId))
const stage = ref<'pending' | 'analyze' | 'edit' | 'done' | 'failed'>('pending')
const detail = ref<MakeoverDetailVO | null>(null)
let cancel: (() => void) | null = null
let pollTimer: number | null = null

onMounted(async () => {
  await fetchSnapshot()
  startSseWithFallback()
})

function startSseWithFallback() {
  cancel = subscribeMakeoverProgress(
    recordId.value,
    (e: any) => {
      if ('stage' in e) {
        stage.value = e.stage === 'analyze' ? 'analyze' : 'edit'
        if (e.status === 'done') stage.value = 'edit'   // analyze done → 进入 edit 阶段
      } else if ('recordId' in e) {
        stage.value = 'done'
        goResult()
      } else if ('message' in e) {
        stage.value = 'failed'
        showFailToast(e.message)
      }
    },
    (err) => {
      console.warn('[Makeover SSE] 断开，降级轮询', err)
      startPolling()
    }
  )
}

function startPolling() {
  stopPolling()
  pollTimer = window.setInterval(async () => {
    const d = await getMakeoverDetail(recordId.value)
    if (d.status === MakeoverStatus.DONE) {
      goResult()
    } else if (d.status === MakeoverStatus.FAILED) {
      stage.value = 'failed'
      showFailToast(d.errorMessage || '生成失败')
      stopPolling()
    } else {
      // 更新阶段映射
      stage.value = d.status === 1 ? 'analyze' : 'edit'
    }
  }, 1500)
}

function stopPolling() {
  if (pollTimer) { clearInterval(pollTimer); pollTimer = null }
}

onBeforeUnmount(() => {
  cancel?.()
  stopPolling()
})

function goResult() {
  stopPolling(); cancel?.()
  router.replace({ name: 'MakeoverResult', params: { recordId: String(recordId.value) } })
}
```

**UI**：使用 `van-steps` 渲染三步进度（待处理 → 文本分析 → 改造出图 → 完成）。

## 八、错误处理与用户体验

### 8.1 错误提示矩阵

| 场景 | 提示方式 |
|---|---|
| 图片超过 8MB | `showToast('图片不超过 8MB')`（van-uploader oversize） |
| 非允许格式 | `showToast('仅支持 jpg / png / webp')` |
| 提交失败 | `showFailToast('提交失败，请稍后再试')` |
| SSE 断连 | 自动降级轮询，**不打扰用户**，仅日志告警 |
| 分析超时 | 进度页 stage=failed，引导「重新提交」 |
| 出图失败 | 结果页允许查看文本建议，顶部黄条提示「改造图生成失败，点击重试」 |

### 8.2 Loading 与空状态

- 提交：`van-button loading`（已内置）
- 进度页：`van-skeleton` 三行骨架
- 历史空：`EmptyState.vue` 复用：「还没有化妆建议，去生成第一条 →」

### 8.3 无障碍

- 所有图标按钮加 `aria-label`
- 颜色对比度 ≥ 4.5:1（依赖 Vant 默认）
- 进度步骤条使用 `role="status"` + `aria-live="polite"`

## 十、测试要点

### 10.1 手工测试矩阵

| 场景 | 预期 |
|---|---|
| 上传 1MB jpg + 选「约会」 + 提交 | 进度页 5s 内收到 analyze running |
| 关闭浏览器再回到 `/makeover/history` | 看到刚才那条记录，状态为「分析中/已完成」 |

| 上传 9MB 图片 | 拦截，提示大小超限 |

| 删除历史记录 | 软删，列表移除；详情页 404 |

## 十一、安全与隐私

1. **鉴权**：所有接口经 `JwtAuthFilter`，前端无 token 拦截不到接口 ✅
2. **CSRF**：multipart + JWT header，前后端分离无需 CSRF ✅
3. **跨用户访问**：后端按 userId 过滤；前端不暴露其他用户 recordId
4. **XSS**：所有 AI 文本用 `v-text` 渲染（不用 `v-html`），列表用 `v-for`
5. **隐私文案**：上传卡片下方常驻 NoticeBar 提示保存与删除路径
