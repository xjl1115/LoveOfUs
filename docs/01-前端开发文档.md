# LoveOfUs 前端开发文档

## 一、项目概述

LoveOfUs 是一款情侣游玩照片存储与分享 Web 应用，用户可将照片按时间线组织管理，支持按时间范围导出照片。前端基于 **Vue 3 + Vite + TypeScript**，适配手机端和桌面端浏览器。

### 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.x | 渐进式前端框架 |
| Vite | 5.x | 构建工具 |
| TypeScript | 5.x | 类型安全 |
| Pinia | 2.x | 状态管理 |
| Vue Router | 4.x | 路由管理 |
| Axios | 1.x | HTTP 请求 |
| Vant | 4.x | 移动端组件库（适配 H5） |
| Day.js | 1.x | 日期处理 |
| ECharts | 5.x | 数据可视化（时间轴） |

---

## 二、页面结构

根据原型图分析，项目包含以下页面（共 7 个核心页面）：

| 页面 | 路径 | 说明 |
|------|------|------|
| 欢迎/登录页 | `/login` | 情侣主题欢迎页，支持登录/注册 |
| 首页时间线 | `/home` | 照片时间线主页面，瀑布流布局 |
| 照片详情 | `/photo/:id` | 单张照片大图查看与元数据 |
| 照片上传 | `/upload` | 批量上传照片，填写日期/地点/描述 |
| 相册管理 | `/albums` | 按事件/地点分组的相册列表 |
| 照片导出 | `/export` | 按时间范围导出照片 |
| 个人中心 | `/profile` | 账号设置、统计信息 |

### 3.1 欢迎/登录页 `/login`

**原型特征：** 暖色调（奶油色 #FFF7EA），竖屏手机尺寸。

**优化设计：**

```
+----------------------------------+
|          ❤️ LoveOfUs              |
|                                   |
|      [情侣插画 / Logo 动画]        |
|                                   |
|      "记录我们的每一刻"            |
|      (副标题：时间会走，爱会停留)   |
|                                   |
|  ┌─────────────────────────┐      |
|  │    手机号 / 邮箱             │      |
|  ├─────────────────────────┤      |
|  │    密码                    │      |
|  └─────────────────────────┘      |
|                                   |
|  [     登  录      ]              |
|                                   |
|  没有账号？立即注册                |
|                                   |
|  --- 其他方式 ---                  |
|  [微信] [QQ] [苹果]              |
+----------------------------------+
```

**交互说明：**
- 顶部展示情侣主题插画（Lottie 动画），背景为渐变暖色调
- 登录表单居中显示，支持手机号/邮箱 + 密码登录
- 底部支持第三方登录（微信/QQ/苹果）

- 移动端全屏展示，桌面端居中卡片式布局（最大宽度 400px）
- 背景可轮播展示情侣照片（从已有照片中随机选取，初次使用显示默认暖色背景）

**移动端适配：**
- 全屏展示，无横向滚动
- 输入框自动获得焦点
- 键盘弹出时页面自动上移

## 六、API 调用封装

### 6.1 Axios 配置

```typescript
// src/utils/request.ts
const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || '/api',
  timeout: 30000,
})

// 请求拦截器 - 携带 Token
request.interceptors.request.use((config) => {
  const token = useUserStore().token
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截器 - 统一错误处理
request.interceptors.response.use(
  (res) => res.data,
  (err) => {
    if (err.response?.status === 401) {
      useUserStore().logout()
      router.push('/login')
    }
    return Promise.reject(err)
  }
)
```

### 6.2 接口封装

```typescript
// src/api/photo.ts
export const photoApi = {
  list: (params: PhotoListParams) => request.get('/photos', { params }),
  detail: (id: number) => request.get(`/photos/${id}`),
  upload: (formData: FormData, onProgress?: ProgressCallback) =>
    request.post('/photos/upload', formData, {
      headers: { 'Content-Type': 'multipart/form-data' },
      onUploadProgress: onProgress,
    }),
  delete: (id: number) => request.delete(`/photos/${id}`),
  update: (id: number, data: PhotoUpdateData) => request.put(`/photos/${id}`, data),
  getTimeline: (params: TimelineParams) => request.get('/photos/timeline', { params }),
  export: (params: ExportParams) => request.post('/photos/export', params, { responseType: 'blob' }),
}

export const albumApi = {
  list: () => request.get('/albums'),
  detail: (id: number) => request.get(`/albums/${id}`),
```

## 十二、照片加载与显示规范

### 12.1 图片多尺寸支持

## 十三、中国足迹地图实现方案

### 13.1 功能概述

在**首页时间线顶部**展示中国地图，根据照片存储的省份信息动态着色。**已有照片的省份**显示暖橙色系，**未去的省份**显示淡灰色，直观展示情侣的旅行足迹。点击省份可直接筛选该省照片，实现地图与时间线的联动交互。

### 13.2 技术选型

| 技术 | 用途 | 说明 |
|------|------|------|
| ECharts | 地图渲染引擎 | `echarts` + `echarts-gl` |
| `echarts-map-china` | 中国地图 GeoJSON 数据 | 包含 34 个省级行政区矢量边界 |
| 后端 API | 提供省份照片统计数据 | `GET /api/user/stats` 返回 `cities` 数组 |

### 13.3 实现步骤

#### 步骤 1：安装依赖

```bash
npm install echarts echarts-map-china
```

#### 步骤 2：在 Vue 组件中加载地图

```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import * as echarts from 'echarts'
import 'echarts-map-china'  // 注册中国地图

const chartRef = ref<HTMLDivElement>()
const totalVisited = ref(0)
const totalProvinces = 34

// 省份照片数据（从后端 API 获取）
interface ProvinceData {
  name: string
  count: number
}

const provinceData = ref<ProvinceData[]>([])

// 当前筛选的省份
const activeProvince = ref<string | null>(null)
const emit = defineEmits<{
  filterByProvince: [province: string | null]
}>()

onMounted(async () => {
  // 获取用户统计数据（含省份照片分布）
  const res = await fetch('/api/user/stats')
  const data = await res.json()
  provinceData.value = data.cities || []
  totalVisited.value = provinceData.value.length

  initChart()
})

function initChart() {
  if (!chartRef.value) return

  const myChart = echarts.init(chartRef.value)

  // 构建省份数值映射
  const mapData = provinceData.value.map(p => ({
    name: p.name,
    value: p.count
  }))

  const option = {
    tooltip: {
      trigger: 'item',
      formatter: (params: any) => {
        if (params.value) {
          return `${params.name}<br/>📸 ${params.value} 张照片`
        }
        return `${params.name}<br/>尚未去过`
      }
    },
    visualMap: {
      min: 0,
      max: Math.max(...provinceData.value.map(p => p.count), 1),
      left: 'left',
      bottom: 10,
      text: ['多', '少'],
      textStyle: { fontSize: 12 },
      inRange: {
        // 颜色渐变：未去过 → 少量 → 大量
        color: ['#E8E8E8', '#FFCCBC', '#FF8A65', '#E64A19', '#BF360C']
      },
      calculable: true
    },
    series: [{
      type: 'map',
      map: 'china',
      roam: true,          // 允许缩放拖拽
      selectedMode: false,
      label: {
        show: true,
        fontSize: 10,
        color: '#333'
      },
      itemStyle: {
        borderColor: '#BDBDBD',
        borderWidth: 1,
        areaColor: '#E8E8E8'  // 默认未去省份颜色
      },
      emphasis: {
        label: { color: '#fff', fontSize: 12 },
        itemStyle: {
          areaColor: '#FF6B6B',
          shadowBlur: 10,
          shadowOffsetX: 0,
          shadowColor: 'rgba(0, 0, 0, 0.2)'
        }
      },
      data: mapData
    }]
  }

  myChart.setOption(option)

  // 省份点击事件 → 筛选/取消筛选本页时间线
  myChart.on('click', (params: any) => {
    if (params.name === activeProvince.value) {
      // 再次点击同省份 → 取消筛选
      activeProvince.value = null
      emit('filterByProvince', null)
    } else if (params.value) {
      // 点击有照片的省份 → 应用筛选
      activeProvince.value = params.name
      emit('filterByProvince', params.name)
    }
  })
}
</script>
```
