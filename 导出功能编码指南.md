## 一、ZIP 压缩包导出

### 概述

前端收集用户选择的照片 ID 列表，后端根据 `photoIds` 查询 `photo` 表的 `storage_path` 字段，使用 `BatchDownloadObjectURL` 批量下载到 ZIP 压缩包中。支持按日期分文件夹、包含照片元数据。

### 前端调用流程

```
Export.vue
  ├─ startExport()
  ├─ 收集用户选中的照片 ID 列表
  ├─ createExport({ photoIds, format: 'zip', options })
  ├─ 轮询 getExportStatus(id) 更新进度
  └─ 完成后调用 downloadExport(id) 下载 Blob 文件
```

#### 4. ExportService 实现 - ZIP 导出核心逻辑

```java
package com.example.lovemap.service.serviceImpl;

import com.example.lovemap.mapper.PhotoMapper;
import com.example.lovemap.model.dto.ExportDTO;
import com.example.lovemap.model.entity.Photo;
import com.example.lovemap.utils.BatchDownloadObjectURL;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.stream.Collectors;
import java.util.zip.ZipEntry;
import java.util.zip.ZipOutputStream;

@Slf4j
@Service
@RequiredArgsConstructor
public class ExportServiceImpl implements ExportService {

    private final PhotoMapper photoMapper;
    private final BatchDownloadObjectURL batchDownloader;

    /**
     * 生成 ZIP 压缩包
     *
     * 流程：
     * 1. 根据 photoIds 查询 photo 表获取 storage_path
     * 2. 构建完整的 OSS URL 列表
     * 3. 使用 BatchDownloadObjectURL 批量下载到临时目录
     * 4. 将临时目录中的文件打包为 ZIP
     * 5. 清理临时目录
     *
     * @param photoIds 照片 ID 列表（前端选中）
     * @param options  导出选项
     * @param userId   用户ID
     * @return 生成的 ZIP 文件路径
     */
    public String generateZip(List<Long> photoIds, ExportDTO options, Integer userId) throws IOException {
        // 1. 查询照片记录
        List<Photo> photos = photoMapper.selectBatchIds(photoIds);
        if (photos == null || photos.isEmpty()) {
            throw new IllegalArgumentException("未找到对应的照片记录");
        }

        // 2. 构建 OSS URL 列表
        List<String> ossUrls = photos.stream()
                .map(Photo::getStoragePath)
                .filter(path -> path != null && !path.isEmpty())
                .collect(Collectors.toList());

        if (ossUrls.isEmpty()) {
            throw new IllegalArgumentException("照片存储路径为空");
        }

        // 3. 创建临时目录，用于存放下载的原图
        Path tempDir = Files.createTempDirectory("export_photos_" + userId);
        Path downloadDir = tempDir.resolve("originals");
        Files.createDirectories(downloadDir);

        // 4. 使用 BatchDownloadObjectURL 批量下载
        int downloaded = batchDownloader.batchDownload(ossUrls, downloadDir.toString());
        log.info("批量下载完成: {}/{} 张照片", downloaded, ossUrls.size());

        // 5. 将下载的文件打包为 ZIP
        Path zipPath = tempDir.resolve("photos_" + System.currentTimeMillis() + ".zip");
        try (ZipOutputStream zos = new ZipOutputStream(new FileOutputStream(zipPath.toFile()))) {
            File[] files = downloadDir.toFile().listFiles();
            if (files != null) {
                for (File file : files) {
                    if (!file.isFile()) continue;

                    // 确定 ZIP 条目名称
                    String entryName = buildZipEntryName(file, photos, options);

                    // 写入 ZIP
                    ZipEntry entry = new ZipEntry(entryName);
                    entry.setSize(file.length());
                    entry.setTime(file.lastModified());
                    zos.putNextEntry(entry);

                    try (FileInputStream fis = new FileInputStream(file)) {
                        byte[] buffer = new byte[8192];
                        int len;
                        while ((len = fis.read(buffer)) != -1) {
                            zos.write(buffer, 0, len);
                        }
                    }
                    zos.closeEntry();
                }
            }

            // 6. 可选：写入元数据文件
            if (options.getIncludeMetadata() != null && options.getIncludeMetadata()) {
                for (Photo photo : photos) {
                    String metaEntryName = "metadata/" + photo.getId() + "_" + photo.getTakenDate() + ".meta.txt";
                    ZipEntry metaEntry = new ZipEntry(metaEntryName);
                    zos.putNextEntry(metaEntry);
                    zos.write(buildMetadata(photo).getBytes());
                    zos.closeEntry();
                }
            }
        }

        // 7. 清理临时目录（删除下载的原图，保留 ZIP）
        cleanTempDirectory(downloadDir);

        return zipPath.toString();
    }

    /**
     * 构建 ZIP 中的文件路径（支持按日期分组）
     */
    private String buildZipEntryName(File file, List<Photo> photos, ExportDTO options) {
        // 从文件名匹配对应的 Photo 记录（BatchDownloadObjectURL 保留了原 objectKey 的目录结构）
        if (options.getGroupByDate() != null && options.getGroupByDate()) {
            // 根据文件名尝试匹配 Photo 的 takenDate
            String fileName = file.getName();
            for (Photo photo : photos) {
                if (photo.getStoragePath() != null && photo.getStoragePath().contains(fileName)) {
                    String dateFolder = photo.getTakenDate().replace("-", "");
                    return dateFolder + "/" + fileName;
                }
            }
        }
        return file.getName();
    }

    /**
     * 构建照片元数据文本
     */
    private String buildMetadata(Photo photo) {
        return String.format(
            "照片ID: %d\n拍摄日期: %s\n地点: %s\n城市: %s\n省份: %s\n描述: %s\n标签: %s\n上传时间: %s",
            photo.getId(), photo.getTakenDate(),
            photo.getLocationName(), photo.getCity(), photo.getProvince(),
            photo.getDescription(), photo.getAiTags(),
            photo.getCreatedAt()
        );
    }

    /**
     * 清理临时目录
     */
    private void cleanTempDirectory(Path dir) throws IOException {
        if (Files.exists(dir)) {
            Files.walk(dir)
                    .sorted(Comparator.reverseOrder())
                    .map(Path::toFile)
                    .forEach(File::delete);
        }
    }
}
```

#### 7. 处理大文件优化

对于大量照片的 ZIP 导出，建议：

- 使用 **分页分批处理**，避免一次性加载过多照片 ID 到内存
- `BatchDownloadObjectURL` 已按 endpoint **分组复用 OSS 客户端**，减少连接开销
- 下载到本地临时目录后 **流式写入 ZIP**，而非先在内存中缓存所有文件
- 定期清理临时目录（`@Scheduled` 定时任务），防止磁盘写满

### 后端 PDF 生成核心逻辑

```java
package com.example.lovemap.service.serviceImpl;

import com.itextpdf.kernel.colors.ColorConstants;
import com.itextpdf.kernel.font.PdfFont;
import com.itextpdf.kernel.font.PdfFontFactory;
import com.itextpdf.kernel.geom.PageSize;
import com.itextpdf.kernel.pdf.PdfDocument;
import com.itextpdf.kernel.pdf.PdfWriter;
import com.itextpdf.layout.Document;
import com.itextpdf.layout.borders.Border;
import com.itextpdf.layout.element.*;
import com.itextpdf.layout.properties.*;
import lombok.extern.slf4j.Slf4j;

import javax.imageio.ImageIO;
import java.awt.image.BufferedImage;
import java.io.*;
import java.net.URL;
import java.util.List;

@Slf4j
public class PdfAlbumGenerator {

    /**
     * 生成 PDF 相册
     *
     * @param photos  照片列表
     * @param options PDF 选项（photosPerPage, coverStyle, includeDescription）
     * @param albumTitle 相册标题
     * @return PDF 文件路径
     */
    public String generatePdf(List<Photo> photos, PdfOptions options, String albumTitle) throws IOException {
        // 1. 创建临时文件
        Path tempDir = Files.createTempDirectory("pdf_export_");
        Path pdfPath = tempDir.resolve("album_" + System.currentTimeMillis() + ".pdf");

        // 2. 初始化 PDF 文档
        PdfWriter writer = new PdfWriter(new FileOutputStream(pdfPath.toFile()));
        PdfDocument pdf = new PdfDocument(writer);
        Document document = new Document(pdf, PageSize.A4);
        document.setMargins(20, 20, 20, 20);

        // 3. 生成封面
        generateCover(document, albumTitle, options.getCoverStyle());

        // 4. 按页添加照片
        List<List<Photo>> pages = partitionPhotos(photos, options.getPhotosPerPage());
        for (List<Photo> pagePhotos : pages) {
            generatePhotoPage(document, pagePhotos, options);
        }

        // 5. 关闭文档
        document.close();

        return pdfPath.toString();
    }

    /**
     * 生成封面页
     */
    private void generateCover(Document document, String title, String coverStyle) {
        // 简约封面
        Paragraph titlePara = new Paragraph(title)
                .setTextAlignment(TextAlignment.CENTER)
                .setFontSize(36)
                .setBold()
                .setMarginTop(200);

        // 浪漫封面（添加装饰元素）
        if ("romantic".equals(coverStyle)) {
            Paragraph subTitle = new Paragraph("Our Love Story")
                    .setTextAlignment(TextAlignment.CENTER)
                    .setFontSize(18)
                    .setFontColor(ColorConstants.PINK);
            document.add(subTitle);
        }

        document.add(titlePara);

        // 添加日期
        Paragraph datePara = new Paragraph("导出日期: " + LocalDate.now().toString())
                .setTextAlignment(TextAlignment.CENTER)
                .setFontSize(12)
                .setFontColor(ColorConstants.GRAY);
        document.add(datePara);

        document.add(new AreaBreak()); // 分页
    }

    /**
     * 生成照片页
     *
     * 根据 photosPerPage 自动排版：
     * - 1 张：居中全页
     * - 2 张：上下各一张
     * - 4 张：2x2 网格
     * - 6 张：2x3 网格
     * - 9 张：3x3 网格
     */
    private void generatePhotoPage(Document document, List<Photo> photos, PdfOptions options) throws IOException {
        int cols = calculateColumns(options.getPhotosPerPage());
        int rows = (int) Math.ceil((double) photos.size() / cols);

        Table table = new Table(cols);
        table.setWidth(UnitValue.createPercentValue(100));

        for (Photo photo : photos) {
            // 下载照片
            BufferedImage image = ImageIO.read(new URL(photo.getStoragePath()));
            Image pdfImage = new Image(com.itextpdf.io.image.ImageDataFactory.create(
                    photo.getStoragePath()));

            // 缩放适配单元格
            pdfImage.setAutoScale(true);

            // 创建单元格
            Cell cell = new Cell();
            cell.add(pdfImage);
            cell.setBorder(Border.NO_BORDER);
            cell.setPadding(5);

            // 添加描述文字
            if (options.isIncludeDescription() && photo.getDescription() != null) {
                Paragraph desc = new Paragraph(photo.getDescription())
                        .setFontSize(8)
                        .setFontColor(ColorConstants.GRAY)
                        .setTextAlignment(TextAlignment.CENTER);
                cell.add(desc);
            }

            table.addCell(cell);
        }

        // 填充剩余空白单元格
        int totalCells = cols * rows;
        for (int i = photos.size(); i < totalCells; i++) {
            table.addCell(new Cell().setBorder(Border.NO_BORDER));
        }

        document.add(table);
        document.add(new AreaBreak()); // 新页面
    }

    private int calculateColumns(int photosPerPage) {
        switch (photosPerPage) {
            case 1: return 1;
            case 2: return 1; // 1列，2行
            case 4: return 2;
            case 6: return 3;
            case 9: return 3;
            default: return 2;
        }
    }

    /**
     * 将照片列表分页
     */
    private List<List<Photo>> partitionPhotos(List<Photo> photos, int pageSize) {
        List<List<Photo>> pages = new ArrayList<>();
        for (int i = 0; i < photos.size(); i += pageSize) {
            int end = Math.min(i + pageSize, photos.size());
            pages.add(photos.subList(i, end));
        }
        return pages;
    }

    @Data
    public static class PdfOptions {
        private int photosPerPage = 4;
        private String coverStyle = "romantic";
        private boolean includeDescription = true;
    }
}
```

## 三、视频影集导出

### 概述

将照片合成 MP4 视频幻灯片。使用 **JCodec**（纯 Java 实现）生成 H.264 编码的 MP4 文件，无需在服务器安装任何原生依赖。

### 新增 Maven 依赖（pom.xml）

```xml
<!-- JCodec - 纯 Java 视频编码库 -->
<dependency>
    <groupId>org.jcodec</groupId>
    <artifactId>jcodec</artifactId>
    <version>0.2.5</version>
</dependency>
<dependency>
    <groupId>org.jcodec</groupId>
    <artifactId>jcodec-javase</artifactId>
    <version>0.2.5</version>
</dependency>
```

### JCodec 方案说明

| 特性 | 说明 |
|------|------|
| **编码方式** | H.264 视频编码，纯 Java 实现 |
| **输入** | `BufferedImage` 序列（从 OSS 下载的图片） |
| **输出** | MP4 文件（.mp4） |
| **音频支持** | JCodec 音频能力有限，背景音乐需后续用 FFmpeg 后期混音或使用 Java 音频库 |
| **优点** | 零原生依赖，部署简单，与项目 JDK 25 兼容 |

### 视频生成核心流程

```
1. 根据 photoIds 查询 photo 表
2. 从 OSS 下载原图到临时目录，统一缩放到 1920x1080
3. 使用 JCodec SequenceEncoder 逐帧写入视频
4. 输出 MP4 文件
5. 清理临时目录
```

### 后端实现核心逻辑

```java
package com.example.lovemap.service.serviceImpl;

import com.example.lovemap.model.entity.Photo;
import lombok.extern.slf4j.Slf4j;
import org.jcodec.api.SequenceEncoder;
import org.jcodec.common.Format;
import org.jcodec.common.io.NIOUtils;
import org.jcodec.common.model.Rational;
import org.jcodec.scale.AWTUtil;

import javax.imageio.ImageIO;
import java.awt.*;
import java.awt.image.BufferedImage;
import java.io.IOException;
import java.io.InputStream;
import java.net.URL;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Comparator;
import java.util.List;

@Slf4j
public class VideoSlideshowGenerator {

    /** 输出帧率：每张照片显示 3 秒 → 0.333 fps */
    private static final int FRAME_RATE_NUM = 1;
    private static final int FRAME_RATE_DEN = 3;

    /** 视频分辨率 1080p */
    private static final int VIDEO_WIDTH = 1920;
    private static final int VIDEO_HEIGHT = 1080;

    /**
     * 生成视频影集
     *
     * @param photos     照片列表（已按拍摄日期排序）
     * @param userId     用户ID
     * @return 生成的 MP4 文件路径
     */
    public String generateSlideshow(List<Photo> photos, Integer userId) throws IOException {
        // 1. 创建临时目录
        Path tempDir = Files.createTempDirectory("video_export_" + userId);
        Path imageDir = tempDir.resolve("images");
        Files.createDirectories(imageDir);

        Path videoPath = tempDir.resolve("slideshow_" + System.currentTimeMillis() + ".mp4");

        try {
            // 2. 下载并预处理照片
            log.info("开始下载并预处理 {} 张照片", photos.size());
            for (int i = 0; i < photos.size(); i++) {
                Photo photo = photos.get(i);
                Path targetPath = imageDir.resolve(String.format("%05d.jpg", i));

                // 下载图片
                try (InputStream in = new URL(photo.getStoragePath()).openStream()) {
                    BufferedImage original = ImageIO.read(in);
                    if (original == null) {
                        log.warn("无法读取图片: {}", photo.getStoragePath());
                        continue;
                    }

                    // 缩放到 1080p（保持宽高比，填充黑边）
                    BufferedImage resized = resizeToFit(original, VIDEO_WIDTH, VIDEO_HEIGHT);
                    ImageIO.write(resized, "jpg", targetPath.toFile());
                }
            }

            // 3. 使用 JCodec 编码为 MP4
            log.info("开始编码视频...");
            try (SequenceEncoder encoder = SequenceEncoder.createSequenceEncoder(
                    NIOUtils.writableChannel(videoPath.toFile()),
                    Rational.R(FRAME_RATE_NUM, FRAME_RATE_DEN))) {

                // 设置视频编码参数
                encoder.withKeyInterval(25);

                // 逐张照片编码帧
                for (int i = 0; i < photos.size(); i++) {
                    Path imagePath = imageDir.resolve(String.format("%05d.jpg", i));
                    if (!Files.exists(imagePath)) continue;

                    BufferedImage frame = ImageIO.read(imagePath.toFile());
                    if (frame == null) continue;

                    // 每张照片按帧率编码为 1 帧（1/3 fps = 每张 3 秒）
                    encoder.encodeNativeFrame(AWTUtil.fromBufferedImage(frame));

                    if ((i + 1) % 10 == 0) {
                        log.info("视频编码进度: {}/{} 张", i + 1, photos.size());
                    }
                }
            }

            log.info("视频生成完成: {}", videoPath);
            return videoPath.toString();

        } catch (Exception e) {
            log.error("视频生成失败", e);
            throw new IOException("视频生成失败", e);

        } finally {
            // 清理临时图片目录
            if (Files.exists(imageDir)) {
                Files.walk(imageDir)
                        .sorted(Comparator.reverseOrder())
                        .map(Path::toFile)
                        .forEach(File::delete);
            }
        }
    }

    /**
     * 将图片缩放到指定尺寸，保持宽高比，不足部分填充黑边
     */
    private BufferedImage resizeToFit(BufferedImage source, int targetW, int targetH) {
        int srcW = source.getWidth();
        int srcH = source.getHeight();

        // 计算缩放比例，使图片完全适配目标区域
        double scale = Math.min((double) targetW / srcW, (double) targetH / srcH);
        int scaledW = (int) (srcW * scale);
        int scaledH = (int) (srcH * scale);

        // 创建目标画布（黑色背景）
        BufferedImage result = new BufferedImage(targetW, targetH, BufferedImage.TYPE_3BYTE_BGR);
        Graphics2D g = result.createGraphics();
        g.setColor(Color.BLACK);
        g.fillRect(0, 0, targetW, targetH);

        // 居中绘制缩放后的图片
        int x = (targetW - scaledW) / 2;
        int y = (targetH - scaledH) / 2;
        g.drawImage(source, x, y, scaledW, scaledH, null);
        g.dispose();

        return result;
    }
}
```

### 配合 BatchDownloadObjectURL 的优化版本

如果照片数量较多，可以先用 `BatchDownloadObjectURL` 批量下载到本地，再统一处理：

```java
public String generateSlideshow(List<Photo> photos, Integer userId,
                                 BatchDownloadObjectURL batchDownloader) throws IOException {
    Path tempDir = Files.createTempDirectory("video_export_" + userId);
    Path downloadDir = tempDir.resolve("originals");
    Path imageDir = tempDir.resolve("frames");
    Files.createDirectories(downloadDir);
    Files.createDirectories(imageDir);

    Path videoPath = tempDir.resolve("slideshow_" + System.currentTimeMillis() + ".mp4");

    try {
        // 1. 批量下载原图
        List<String> ossUrls = photos.stream()
                .map(Photo::getStoragePath)
                .filter(p -> p != null && !p.isEmpty())
                .toList();
        batchDownloader.batchDownload(ossUrls, downloadDir.toString());

        // 2. 统一缩放到 1080p
        File[] files = downloadDir.toFile().listFiles((dir, name) ->
                name.matches("(?i).+\\.(jpg|jpeg|png|webp)$"));
        if (files == null || files.length == 0) {
            throw new IOException("没有可处理的图片文件");
        }

        // 按文件名排序保证顺序
        java.util.Arrays.sort(files);

        for (int i = 0; i < files.length; i++) {
            BufferedImage original = ImageIO.read(files[i]);
            if (original == null) continue;

            BufferedImage resized = resizeToFit(original, VIDEO_WIDTH, VIDEO_HEIGHT);
            ImageIO.write(resized, "jpg", imageDir.resolve(String.format("%05d.jpg", i)).toFile());
        }

        // 3. JCodec 编码
        try (SequenceEncoder encoder = SequenceEncoder.createSequenceEncoder(
                NIOUtils.writableChannel(videoPath.toFile()),
                Rational.R(FRAME_RATE_NUM, FRAME_RATE_DEN))) {

            for (int i = 0; i < files.length; i++) {
                Path framePath = imageDir.resolve(String.format("%05d.jpg", i));
                if (!Files.exists(framePath)) continue;

                BufferedImage frame = ImageIO.read(framePath.toFile());
                if (frame != null) {
                    encoder.encodeNativeFrame(AWTUtil.fromBufferedImage(frame));
                }
            }
        }

        log.info("视频生成完成: {}", videoPath);
        return videoPath.toString();

    } finally {
        // 清理临时目录
        for (Path dir : new Path[]{downloadDir, imageDir}) {
            if (Files.exists(dir)) {
                Files.walk(dir)
                        .sorted(Comparator.reverseOrder())
                        .map(Path::toFile)
                        .forEach(File::delete);
            }
        }
    }
}
```

### 视频导出优化建议

1. **图片预处理**：上传时就生成 1080p 缩略图，减少导出时的缩放计算
2. **缓存机制**：相同照片组合生成的视频可缓存到 OSS，下次直接返回下载链接
3. **分页处理**：照片过多时分批处理，避免内存溢出
4. **画质调节**：调整 `SequenceEncoder` 的位率参数（如 `encoder.withBitrate(5000000)` 设置为 5Mbps）

### 统一任务管理

三种导出方式共用相同的任务管理逻辑：

1. **创建任务**：插入 `export_record` 表，状态 `pending`
2. **异步执行**：通过 `@Async` 线程池执行具体生成逻辑
3. **状态更新**：实时更新 `export_record.status`
4. **文件管理**：生成的文件保存在服务器临时目录，定期清理
5. **下载**：通过 `ResponseEntity<Resource>` 返回文件流

```java
@Bean("exportTaskExecutor")
public Executor exportTaskExecutor() {
    ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
    executor.setCorePoolSize(2);       // 核心线程数（最多同时处理 2 个导出任务）
    executor.setMaxPoolSize(4);        // 最大线程数
    executor.setQueueCapacity(10);     // 队列容量
    executor.setThreadNamePrefix("export-");
    executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
    executor.initialize();
    return executor;
}
```

```java
public void cleanExpiredExports() {
    List<ExportRecord> expiredRecords = exportMapper.findExpiredRecords();

        try {
            Files.deleteIfExists(Paths.get(record.getFilePath()));
```
